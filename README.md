# khoadev-legal

Trang pháp lý cho các ứng dụng của Khoa Dev (dùng cho Meta/Facebook App).

- `/` — trang tổng hợp
- `/privacy` — Chính sách quyền riêng tư (Privacy Policy) — dùng làm Privacy Policy URL cho app “Khoa Dev Page Manager”
- `/terms` — Điều khoản dịch vụ (Terms of Service)

Deploy: Vercel (static, cleanUrls).
